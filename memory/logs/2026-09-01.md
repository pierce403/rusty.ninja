# 2026-09-01

- Fixed the endgame rating stall: a correct calibrated challenge at difficulty
  9.9 or higher can now award exact level 10 with the default `pretty-sure`
  confidence. The update uses the uncertainty produced by the current answer,
  so the final calibration answer completes mastery immediately. Guesses and
  easier-question grinding remain unable to reach exact level 10.
- Added rating regressions for default-confidence mastery, insufficient
  calibration, and guessed top-tier answers. Release gates pass locally.
- Follow-up testing at the owner's actual level 9.93 exposed a second endgame
  issue: a difficulty-10 certain success gained only about 0.0035 and displayed
  as `±0.00`. Added a top-tier gain floor that awards at least 0.015 in that
  worst-case calibrated scenario, plus adaptive three-decimal feedback for any
  remaining nonzero sub-cent changes. The regression reaches exact mastery from
  9.93 within four correct difficulty-10 certain answers; all 65 tests and the
  production/PWA build pass.
